# Загрузка событий групп и аналитика вовлечённости

Учебный проект на Airflow, pandas, Vertica и SQL: обработка журнала событий групп, загрузка в staging и аналитические запросы по активности участников.

## Задача

Подготовить события участия в группах для анализа вовлечённости и конверсии участников в пользователей, отправляющих сообщения.

## Реализация

- Предобработка CSV: nullable-тип `Int64` для `user_id_from`.
- Загрузка через Vertica COPY с обработкой ошибок, commit/rollback и таблицей отклонённых строк.
- SQL для связи пользовательской активности и групп, истории авторизаций и показателей участия.

## Структура

- [src/dags/load_group_log_dag.py](src/dags/load_group_log_dag.py) — предобработка и загрузка.
- [src/dags/sprint_6_dag_get_groups_log.py](src/dags/sprint_6_dag_get_groups_log.py) — DAG получения данных.
- [src/sql](src/sql) — DDL и аналитические запросы.

## Требования к запуску

Нужны Airflow с Vertica provider, pandas, Vertica и учебные исходные данные.
Подключение Airflow: `vertica_conn`.
Файл журнала должен находиться в `/data/group_log.csv`; целевая схема в коде привязана к учебному окружению.

## Ограничения

Автономное demo без Vertica и учебных источников пока отсутствует.
Перед переносом необходимо вынести пути и имя схемы в настройки, проверить порядок SQL-загрузок и повторный запуск.
Формулы конверсии следует документировать вместе с периодом наблюдения и правилами отбора участников.

Проект выполнен в рамках учебной программы.
